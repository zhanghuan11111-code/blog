Markdown 写作入门指南

发表于 2026-10-07 分类于 技术笔记

本文是一篇 Markdown 语法示例，同时也方便你查看博客的排版效果。写文章时可以直接套用这里的写法。

Markdown 是一种轻量级的标记语言，用纯文本就能写出结构清晰的文档，是写博客和笔记的必备技能。

标题

在文字前加 #，数量表示级别，最多六级：

强调与引用

  • 斜体：用 *文字*
  • 加粗：用 **文字**
  • 加粗斜体：用 ***文字***
  • 行内代码：用反引号包裹
  • 删除线：这是删除的内容

引用文字用 > 开头：

学而不思则罔，思而不学则殆。

列表

无序列表：

  • 苹果
  • 香蕉
  • 橙子

有序列表：

  1. 第一步
  2. 第二步
  3. 第三步

代码块

用三个反引号包裹，并标注语言：

表格

语法 效果
**粗体** 粗体
*斜体* 斜体
`代码` 代码

链接与图片

小结

掌握上面这些基础语法，就足够写出漂亮的博客文章了。更多语法细节可以参考 Markdown 官方语法说明。

写博客时记住一句话：先写完，再改好。坚持比完美更重要。

为什么选择 Hexo

个人博客的方案有很多，常见的包括 WordPress、Hugo、Hexo、VitePress 等。最终选择 Hexo，主要是看中它：

  • 轻量快速：基于 Node.js，本地生成纯静态页面，访问速度快
  • 生态成熟：主题丰富，插件众多，社区活跃
  • 写作简单：用 Markdown 写作，专注内容本身

欢迎来到我的个人博客！

之所以搭建这个博客，是想给自己找一个「长期主义」的角落：把学到的知识沉淀下来，把生活里值得记录的瞬间留下来，也通过写作逼自己去思考和总结。

这个博客会写些什么

  • 技术笔记：学习过程中的知识点、踩坑记录、实用技巧
  • 项目分享：自己做的小项目、实践心得
  • 生活随笔：读书、旅行、日常的碎碎念

关于坚持写作

写作是一件「投入当下、收益未来」的事。很多想法当下觉得清楚，过一段时间再看往往已经模糊。把它们写下来，既是整理，也是留给未来的自己一份礼物。

所以，就从今天开始吧。愿这个博客能陪你（也陪我）一起成长。
