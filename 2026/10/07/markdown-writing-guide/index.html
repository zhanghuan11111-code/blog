Markdown 写作入门指南

发表于 2026-10-07 分类于 技术笔记

本文是一篇 Markdown 语法示例，同时也方便你查看博客的排版效果。写文章时可以直接套用这里的写法。

Markdown 是一种轻量级的标记语言，用纯文本就能写出结构清晰的文档，是写博客和笔记的必备技能。

强调与引用

  • 斜体：用 *文字*
  • 加粗：用 **文字**
  • 加粗斜体：用 ***文字***
  • 行内代码：用反引号包裹
  • 删除线：这是删除的内容

引用文字用 > 开头：

学而不思则罔，思而不学则殆。

列表

无序列表：

  • 苹果
  • 香蕉
  • 橙子

有序列表：

  1. 第一步
  2. 第二步
  3. 第三步

语法 效果
**粗体** 粗体
*斜体* 斜体

掌握上面这些基础语法，就足够写出漂亮的博客文章了。更多语法细节可以参考 Markdown 官方语法说明。
