发表于 2026-10-07 分类于 技术笔记

本文记录了本博客从零到上线的搭建过程，作为技术笔记的第一篇，也供有同样需求的朋友参考。

为什么选择 Hexo

个人博客的方案有很多，常见的包括 WordPress、Hugo、Hexo、VitePress 等。最终选择 Hexo，主要是看中它：

  • 轻量快速：基于 Node.js，本地生成纯静态页面，访问速度快
  • 生态成熟：主题丰富，插件众多，社区活跃
  • 写作简单：用 Markdown 写作，专注内容本身

常用命令速查

命令 作用
hexo new "文章标题" 新建一篇文章
hexo new page "about" 新建一个页面（如关于页）
hexo clean 清理缓存
hexo generate 生成静态文件
hexo server 本地预览
hexo deploy 部署到远程
